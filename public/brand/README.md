# innovation.today – Wortmarke

Reine Wortmarke ohne Bildzeichen. **Nunito Bold** (SIL Open Font License), alle SVGs in Pfade umgewandelt.
Die Schriftdatei Nunito-Variable.ttf (Gewichte 200–1000) liegt bei, für Self-Hosting auf der Website.

**Farben:** `innovation.` Navy #14304A · `today` Teal #0F766E · auf dunklem Grund: Weiß + Mint #5EEAD4 · Nachtblau #0F2540

| Datei | Einsatz |
|---|---|
| wordmark_light | Standard, transparenter Hintergrund |
| wordmark_light_bg | Standard auf Weiß (auch OG-Image-Basis) |
| wordmark_dark | Dunkle Hintergründe |
| wordmark_mono_navy / _white | Einfarbig für Druck, Stempel, Gravur |
| favicon_navy / _teal / _light | Browser-Tab, App-Icon, Profilbild – Kürzel „i.t" |

**Regeln:** Mindestbreite 100 px / 25 mm · Schutzraum = Höhe des „i" · nicht drehen, nicht verzerren, keine Verläufe.
